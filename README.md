# ComfyUI + MiniMax H3: what everything actually does

A plain-English guide to the parts, file names and settings of MiniMax H3 in ComfyUI.

Every entry answers three things: what it is, what it does to your video, sound or wait, and what to set it to. The sizing advice is written for a 16 GB card with 32 GB of RAM.

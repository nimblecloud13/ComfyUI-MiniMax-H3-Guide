# ComfyUI in plain English: what everything actually does

Guides to running current models in ComfyUI, written for people who are tired of definitions that define nothing.

Every entry answers three things: what it is, what it does to your picture, video or wait, and what to set it to.

| Guide | What the model makes | PDF | HTML |
|---|---|---|---|
| **MiniMax H3** | Video with sound | [PDF](ComfyUI_MiniMax_H3_Guide.pdf) | [HTML](ComfyUI_MiniMax_H3_Guide.html) |
| **Wan 2.2** | Video | [PDF](ComfyUI_Wan_2.2_Guide.pdf) | [HTML](ComfyUI_Wan_2.2_Guide.html) |
| **Qwen Image 2.1** | Images, image editing, transparent backgrounds | [PDF](ComfyUI_Qwen_Image_2.1_Guide.pdf) | [HTML](ComfyUI_Qwen_Image_2.1_Guide.html) |
| **Krea 2** | Images | [PDF](ComfyUI_Krea_2_Guide.pdf) | [HTML](ComfyUI_Krea_2_Guide.html) |

Each guide has the same seven sections: the big picture, what the model does, the parts, file names, settings, your hardware, first run.

The PDF opens right here on GitHub. The HTML is the same guide as one self-contained page with a section bar that follows you down the page. GitHub shows HTML files as source code, so download the file and open it in your browser.

The sizing advice is written for a 16 GB card with 32 GB of RAM, with notes for smaller cards.
